# FL 350

Le site **FL 350** est un projet personnel autour de l'aéronautique.
L'objectif principal est de créer un espace pour déposer des photos d'avions et dans un second temps de créer une carte en direct des avions au niveau de l'aéroport.

Composition du site :

- Accueil
- Photos
- Carte
